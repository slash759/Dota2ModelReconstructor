# Legacy MORPH tools

Place the original morph reconstruction tools here unchanged.

Expected files from the supplied MORPH bundle:
- flex.exe
- flexRules.exe
- all DLL/runtime/support files shipped with those executables

These are treated as black-box external tools. Do not decompile or modify them.

Runtime working files such as `compiled.txt` and generated output must not be committed here; the application will create a temporary working directory when these tools are integrated.
