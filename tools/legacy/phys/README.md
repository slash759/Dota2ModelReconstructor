# Legacy PHYS tools

Place the original PHYS reconstruction tools here unchanged.

Expected files from the supplied PHYS bundle:
- blendphys.exe
- clothEffect.exe
- physvmdl.exe
- all DLL/runtime/support files shipped with those executables

These are treated as black-box external tools. Do not decompile or modify them.

Runtime working files such as `phys.txt` and generated output must not be committed here; the application will create a temporary working directory when these tools are integrated.
